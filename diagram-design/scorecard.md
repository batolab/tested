# Public scorecard — diagram-design real test

Repo under test: cathrynlavery/diagram-design (plugin version 2.6.136), https://github.com/cathrynlavery/diagram-design
Method: the repository was cloned and its skill was followed exactly as documented. The headline type count was verified three independent ways inside the skill's own documentation and files. The repository's own example prompt was then run as an A/B test: once as a plain default Mermaid render of the same content (no skill), and once drawn by an agent following the skill (default skin). The resulting single HTML file was audited for external references, opened directly from disk with no server, checked with the repository's own self-check script, exported to PNG with the packaged helper, and re-skinned with a custom brand palette through the style guide's token mechanism.
Claim check — "45 diagram types": CONFIRMED. Three independent counts (rows of the Visual-type guide table in SKILL.md, unique type-*.md links in that table, and the guide files actually present under references/) each give exactly 45.
Claim check — "one self-contained HTML file": CONFIRMED with one qualification. The generated file is 9,281 bytes / 139 lines with no scripts and no external images; the only external reference in it is one Google Fonts stylesheet link. It opens and renders fully from a file:// address with no web server.
Results:
- Type count: 45 by all three counting methods — matches the claim.
- Install: the documented `npx skills add cathrynlavery/diagram-design` works, but it is interactive by default (it asks which agents to install into and cancels when there is no terminal). With `--agent '*' -y` it installs non-interactively into .agents/skills/diagram-design. The installer's own security panel rated the skill Gen: Safe, Socket: 0 alerts, Snyk: Med Risk, and warned that skills run with full agent permissions — reported here exactly as displayed.
- Baseline (no skill): the same content as a default Mermaid 10 render — purple default theme, plain rectangles for frontend/backend, cylinder shapes for the two stores, curved arrows, no relationship labels, no legend.
- With skill: a single HTML file whose diagram uses typed nodes (client / focal app tier / data stores), orthogonal connectors with masked labels (HTTPS, GET/SET, SQL), and a legend strip. The repository's own self-check passed it on the first attempt (exit code 0).
- PNG export: the packaged export_png.py rendered the diagram at 1920×1200; visual inspection found every arrow label fully readable, nothing covered by a box, no overflowing text.
- Brand re-skin: the same diagram re-skinned through the style guide's token mechanism (dark paper #0B0E14, link blue #58A6FF, amber accent #F0B43C on the single focal node only) also passed the self-check on the first attempt and exported cleanly.
- Vertical variant: the same diagram was also drawn with the primary flow running top to bottom instead of left to right — a direction the Architecture guide explicitly allows — with identical components, relationships and labels, and re-skinned with the same brand tokens; both vertical files passed the self-check on the first attempt. The presentation video shows this vertical variant (same tested diagram, same content, flow direction changed) so the whole diagram fits a portrait video frame without any cropping.
Limitations (stated plainly): only 1 of the 45 diagram types was exercised (Architecture); the other 44 are counted, not tested. The baseline is a default Mermaid render of the same content — the standard out-of-the-box comparison — not a specific model's freehand drawing. The skill's rule set is thick (a 31 KB SKILL.md plus a guide per type), and following it loosely does produce flawed output: an earlier practice diagram drawn the same morning (a pipeline diagram, not part of this pack) passed the self-check yet its exported PNG showed two arrow labels partially covered by boxes drawn after them — the packaged self-check does not catch that class of error, so a visual inspection of the rendered output is still required. Exporting to PNG requires installing Playwright and a headless Chromium; the HTML itself needs nothing. The install command is interactive unless the non-interactive flags are added, and the skill asks the user to confirm a brand skin before the first branded diagram.
Files in this folder: the test instructions used; the inputs — prompt.txt (the repository's own example prompt, verbatim) and baseline.mmd (the Mermaid source of the no-skill baseline); raw outputs — diagram-with-skill.html (default skin), diagram-lab-branded.html (brand re-skin), diagram-with-skill-vertical.html and diagram-lab-branded-vertical.html (the vertical-layout variants of the same two) and self-check-output.txt (the checker's verbatim output for all four files).
